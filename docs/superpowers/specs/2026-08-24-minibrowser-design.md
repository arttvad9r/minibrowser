# Минималистичный Android-браузер — дизайн

Дата: 2026-08-24
Статус: утверждён (обсуждение в чате), рабочий проект `minibrowser`

## Цель

Личный минималистичный браузер для Android с двумя ключевыми возможностями:

1. Встроенная блокировка рекламы (полноценная, уровня uBlock Origin).
2. Закадровый автоперевод видео (как в Яндекс.Браузере) на YouTube и других сайтах.

Принципы: минимум функций, современный UI, скорость, отсутствие лишнего.

Не для публикации в магазинах: личные debug/release-сборки, ставятся вручную.

## Стек и платформа

- Kotlin, Jetpack Compose, один Gradle-модуль.
- Движок: GeckoView (Mozilla, Maven `org.mozilla.geckoview`).
- minSdk 26, target — последняя стабильная; личное устройство OnePlus 13s (Android 15+).
- Сборка на NixOS: JDK 17 через nix, Android SDK `~/Android/Sdk`.
- Mozilla Android Components НЕ используем — работаем напрямую с API GeckoView.

## Архитектура

```
MainActivity (Compose)
├─ UI: адресная строка снизу, шторка вкладок, меню, настройки,
│      стартовая страница с плитками закладок   [Compose state ← делегаты]
├─ TabManager: список GeckoSession (+ приватные), восстановление после смерти процесса
├─ ExtensionLoader: ensureBuiltIn() двух расширений из assets/extensions/
├─ FaviconStore: кэш иконок на диске (files/icons/)
└─ Store:
   ├─ DataStore<Preferences> — настройки (поисковик, тема, вкл/выкл uBO)
   ├─ Room — закладки (плитки), история посещений
   └─ JSON-файл — открытые вкладки (URL + приватность-флаг не сохраняется)
```

Слой один, без интерфейсов-однодневок: делегаты GeckoView → StateFlow → Compose.

## Ключевые возможности

### Блокировка рекламы

uBlock Origin встраивается как built-in WebExtension:

- Источник: готовый релизный `.xpi` uBO (GPLv3) с GitHub, распакованный в
  `src/main/assets/extensions/ublock/`.
- Установка: `WebExtensionController.ensureBuiltIn("resource://android/assets/extensions/ublock/", "uBlock0@raymondhill.net")`.
- Подпись Mozilla не нужна (built-in путь). Обновление фильтров делает сам uBO.
- Обновление самого uBO: ручная замена ассетов при пересборке (личный проект).
- Тумблер в меню: `WebExtensionController.setEnabled(uBO, bool)`.

### Перевод видео (VOT)

Voice-Over-Translation (ilyhalight/voice-over-translation, MIT):

- Источник: `.xpi` из релизов репозитория либо сборка `bun run autobuild`;
  распакованный в `assets/extensions/vot/`, тот же `ensureBuiltIn`.
- Возможности VOT из коробки: закадровый перевод (API Яндекса), автоперевод
  при открытии видео (галочка в настройках VOT), субтитры, раздельная громкость,
  прокси на случай недоступности серверов Яндекса.
- Наша работа: только установка и корректная среда:
  - автовоспроизведение медиа разрешено по умолчанию (требование VOT);
  - UA: начинаем со штатного мобильного; если VOT не подхватывает плеер
    мобильного YouTube — используем десктопный UA через уже имеющийся тумблер
    «Версия для ПК» (автоправило для видеохостов добавляем только если
    тумблера окажется недостаточно).

### Стартовая страница / визуальные закладки

Пустая вкладка = стартовый экран:

- Поле поиска (поисковик по умолчанию) + сетка плиток 4×N: иконка + название сайта.
- Закладки = плитки, отдельного списка нет. Меню → «Закладки» открывает ту же
  сетку на весь экран.
- Добавление: меню → «В закладки» (сохраняет URL, заголовок, домен).
- Удаление/переименование: долгий тап по плитке (bottom sheet: открыть, изменить
  название, удалить).
- Иконки: сервис `https://icons.duckduckgo.com/ip3/<домен>.ico`,
  скачивается один раз, кэш в `files/icons/<md5(host)>.png`.

  ```kotlin
  // ponytail: иконки через DDG-сервис (уходит наружу только домен);
  // заменить на парсинг <link rel="icon"> страницы, если нужна автономность
  ```

- Если закладок нет — сетка скрыта, показывается поле поиска по центру.

## Интерфейс

- Нижняя панель: омнибокс (URL/поиск, подсказки из истории и закладок),
  счётчик вкладок, кнопка меню.
- Прогресс загрузки — тонкая линия над панелью.
- Меню: Новая вкладка · Приватная вкладка · В закладки · Закладки · История ·
  Найти на странице · Версия для ПК · Скачать (DownloadManager) · Поделиться ·
  Блокировка рекламы (переключатель) · Настройки.
- Шторка вкладок: список карточек (заголовок + иконка + крестик), свайп/крестик — закрыть.
- Приватные вкладки: `GeckoSessionSettings.PRIVATE_MODE`, не сохраняются и не пишут историю.
- Тема: системная / светлая / тёмная (Material 3, dynamic color где доступен).
- Настройки (один экран): поисковик (Google/DDG/Yandex/Bing/кастомный), тема,
  домашняя страница, тумблер uBO, «Очистить данные».

## Хранение данных

| Что | Где |
|---|---|
| Настройки | DataStore<Preferences> |
| Закладки | Room: `bookmarks(url PK, title, host, position)` |
| История | Room: `history(url PK, title, visitedAt)` |
| Открытые вкладки | JSON в filesDir (kotlinx.serialization) |
| Иконки | файлы `files/icons/` |

Подсказки омнибокса: LIKE-запросы по истории и закладкам, топ-10 по частоте/свежести.

## Ошибки и восстановление

- Ошибка загрузки страницы — штатная страница ошибки Gecko.
- Убийство процесса системой — вкладки восстанавливаются из JSON при старте.
- Краш сессии (`ContentDelegate.onCrash`) — пересоздание сессии с тем же URL.
- Отсутствие сети — стандартное поведение движка.

## Риски

1. **VOT × мобильный плеер** — главный технический риск. Проверяется первым на
   эмуляторе: youtube.com в браузере, включение перевода, автоперевод.
2. uBO — расширение MV2; если Firefox удалит поддержку MV2, фиксируем последний
   рабочий релиз uBO. Для личного использования приемлемо.
3. DDG-сервис иконок требует сеть и отправляет домен наружу (принято, см. ponytail-комментарий).
4. NixOS: нужен JDK17 (nix) + local.properties на SDK; проверить до первого запуска.

## Чего НЕ делаем (YAGNI)

Синхронизация, магазин/менеджер расширений, режим чтения, RSS/ленты новостей,
жесты, кастомизация внешнего вида, собственный переводчик страниц/озвучка,
поддержка userscript-менеджеров, PWA-установка, ночной режим по расписанию.

## Проверки

- JVM-тесты: сериализация вкладок (JSON round-trip), репозиторий закладок/истории
  (Room in-memory), генератор URL поисковика.
- Эмулятор (ручной прогон): реклама на тестовой странице (d3ward.github.io/toolz/adblock-test),
  перевод видео на YouTube через VOT, плитки закладок, приватная вкладка без истории.
